# PocketSmart-AI - AI-powered Smart Budget and Expense Tracker
## Naan Mudhalvan & SmartBridge - Generative AI Project 2026

### 📌 Project Description
PocketSmart-AI is a personal finance assistant for students. It uses Gemini 3 Flash to answer budgeting, saving, and expense questions in simple language.

### 🎯 Problem Statement
Students don't track expenses. PocketSmart gives instant, smart financial advice 24/7.

### 🏗️ Architecture
- Frontend: Flask + HTML/CSS
- Backend: Python
- AI Model: gemini-3-flash-preview (google-genai SDK)
- API: Gemini Generate Content

### ⚙️ Implementation (Phase-wise)
**Phase 1:** Setup .env with GEMINI_API_KEY
**Phase 2:** Installed new SDK: google-genai, flask, python-dotenv
**Phase 3:** Built app.py with client.models.generate_content(model="gemini-3-flash-preview")
**Phase 4:** Tested: Input "How to save money as student?" -> AI replies successfully
**Phase 5:** Added Web UI for chat
